## 📌 About The Project

**Al-Faisal** is a modern and comprehensive **Business Management & Accounting System** developed using **Flutter**.

The application is designed to help businesses manage their daily operations through a unified and easy-to-use platform.

It brings together essential business functions such as:

* 📦 Products Management
* 🗂️ Categories Management
* 👥 Customers Management
* 🚚 Suppliers Management
* 🛒 Purchases Management
* 💰 Sales & Profits
* 📊 Financial Statistics
* 📋 Dynamic Data Tables
* 💾 Saved Tables
* 📈 Data Visualization

The main goal of the project is to provide a **simple, organized, and modern solution for managing business operations and financial data**.

---

# ✨ Key Features

## 🏠 Dashboard

A centralized dashboard that provides quick access to all major sections of the system.

Users can easily navigate between products, categories, customers, suppliers, purchases, saved tables, and financial information.

---

## 📦 Product Management

The system provides a dedicated product management module where users can:

* Add products
* Edit products
* Delete products
* Organize products
* Manage product information
* Connect products with categories

---

## 🗂️ Category Management

Categories can be created and managed dynamically.

Each category can contain its own structured data, making the system flexible for different types of businesses.

---

## 👥 Customer Management

A dedicated customer management system allows users to:

* Add customers
* Edit customer information
* Delete customers
* View customer records
* Organize customer data

---

## 🚚 Supplier Management

The supplier section allows businesses to keep their supplier information organized and accessible.

---

## 🛒 Purchase Management

The application provides an organized interface for managing purchasing operations and storing purchase-related data.

---

## 💰 Sales & Profit Management

The system provides financial tracking features for monitoring:

* Sales
* Revenue
* Expenses
* Profits
* Financial performance

---

## 📊 Financial Data Visualization

Financial information is represented using charts and visual components to make important business data easier to understand.

---

## 📋 Dynamic Data Tables

One of the main features of the application is the **dynamic table system**.

Users can create and manage structured data based on selected categories instead of being limited to a single predefined table.

This makes the application more flexible and suitable for different business workflows.

---

## 💾 Saved Tables

Important tables and business data can be saved and accessed later.

This allows users to maintain organized records without losing previously entered information.

# ⚙️ Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Business-Management-System.git
```

## 2. Navigate to the Project

```bash
cd Business-Management-System
```

## 3. Install Dependencies

```bash
flutter pub get
```

## 4. Run the Application

```bash
flutter run
```
